# Вимір: цикломатична складність .ts Осавула і SonarQube на двох SHA Руни

## Умови

- Дата: 2026-11-25.
- Ревізія Осавула: `844a7f5692393453f3f65c8e81d1723b08b0d808`.
- Методика: `ts-cyclomatic`, версія 1.
- Збірка: `cargo build --release`, toolchain `1.100.0`, `x86_64-pc-windows-msvc`.
- Команда: `osavul complexity <SHA>`, виконана в Git-клоні Руни.
- Джерело порівняння: збережені звіти SonarQube формату v2 (поле `cyclomatic` кожного файла).
- Версія SonarQube: невідома.

## Область

Усі звичайні відстежувані файли `.ts` у деревах двох комітів, включно з тестами й `.d.ts`. Поза звіркою: `.tsx`, інші мови, когнітивна складність, дублювання та локальний режим `--path`.

## Проєктні суми SonarQube

За всіма мовами SonarQube дає 101 547 для першого SHA таблиці й 102 055 для другого; зміна по проєкту становить +508. Ці проєктні суми не порівнюються із сумами для `.ts`.

## Межі виміру

Порівняно всі 664 файли на першому SHA і всі 665 на другому. Кожне пофайлове значення `cyclomatic` збіглося точно, тож взаємної компенсації розбіжностей немає. Вимір виконано поза цією задачею: підсумки перенесено без повторного запуску звірки. Вхідні JSON у репозиторії Осавула не зберігаються. Для повтору виміру Осавула за наведених умов достатньо повного SHA Руни й команди `osavul complexity <SHA>`.
