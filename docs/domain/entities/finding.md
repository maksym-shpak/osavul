# Сутність: Знахідка

## Призначення

Знахідка — одне спрацювання правила `osavul check` у файлі. Людина чи агент відкриває вказаний шлях, переходить до вказаного рядка й бачить ключове слово `fn` оголошення, яке аналізатор вважає проблемним.

Єдине чинне правило — `empty-test`, нині з реалізацією для Rust; межу рушія й правила описує [ADR-0004](../../architecture/decisions/0004-check-engine-and-rules.md). Воно охоплює звичайну вільну функцію на верхньому рівні файла або у вбудованому модулі, що має єдиний зовнішній атрибут `#[test]` і не має документаційного коментаря при оголошенні. Якщо тіло порожнє або містить лише пропуски й звичайні коментарі, це знахідка. Навіть один виклик допоміжної функції вже є вмістом тіла, тож знахідки не буде.

## Інваріанти

- На кожне спрацювання у stdout припадає запис `<шлях>:<рядок>: empty-test: тест порожній: напишіть перевірку в тілі тесту або видаліть його` із завершальним переносом рядка; повідомлення є частиною контракту. Для явного файла шлях зберігає написання аргументу, включно з початковим `./`. Для теки це аргумент, `/` (якщо аргумент ще не закінчується роздільником) і відносний шлях файла; його можна відкрити з поточної теки. Рядок — фізичний рядок ключового слова `fn`, від 1, навіть коли атрибут займає кілька рядків.
- Записи впорядковано за байтами шляху, числовим рядком та ідентифікатором правила; повтори зберігаються. За того самого входу й середовища повторна перевірка дає байтово однаковий звіт і той самий код завершення.
- Код `0` — усі файли перевірено, знахідок немає (зокрема порожній відбір), `1` — є знахідки; в обох випадках stderr порожній. Код `2` має пріоритет.
- Помилка аргументів, відсутній шлях, непідтримуваний явний файл або неповний перелік теки дає код `2`, діагностику в stderr і порожній stdout. Помилка читання, UTF-8, розбору чи подання шляху окремого файла відкидає лише його знахідки: причина зі шляхом іде в stderr, знахідки решти друкуються, код `2`. Шлях знахідки, який не вміщується в один запис (наприклад, ім'я з переносом рядка), — така сама помилка файла. Відмова запису в stdout також дає код `2`.

## Корпус прикладів

Три пари «знахідка — чистий приклад» у `tests/fixtures/empty-rust-test/` показують, яка мінімальна зміна прибирає спрацювання. У `expected.tsv` один рядок даних відповідає одному файлу; три поля розділені табуляцією, UTF-8: `path` — шлях від каталогу корпусу, `pair` — ідентифікатор пари, `lines` — `[N]` для очікуваної позиції або `[]` для чистого прикладу. Одинична позиція — властивість прикладів цього корпусу: кілька знахідок в одному файлі покриває окремий CLI-тест. Докладніше — у [README корпусу](../../../tests/fixtures/empty-rust-test/README.md).
