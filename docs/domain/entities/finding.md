# Сутність: Знахідка

## Призначення

Знахідка — одне спрацювання правила `osavul check` на оголошенні у файлі. Людина чи агент відкриває вказаний шлях, переходить до вказаного рядка й бачить ключове слово `fn` оголошення, яке аналізатор вважає проблемним.

Єдине чинне правило — `empty-rust-test`. Воно охоплює звичайну вільну функцію на верхньому рівні файла або у вбудованому модулі, що має єдиний зовнішній атрибут `#[test]` і не має документаційного коментаря при оголошенні. Якщо тіло порожнє або містить лише пропуски й звичайні коментарі, це знахідка. Навіть один виклик допоміжної функції вже є вмістом тіла, тож знахідки не буде.

## Інваріанти

- На кожне спрацювання у stdout припадає запис `<шлях>:<рядок>: empty-rust-test` із завершальним переносом рядка. Шлях зберігає написання аргументу, включно з початковим `./`. Рядок — фізичний рядок ключового слова `fn`, від 1, навіть коли атрибут займає кілька рядків.
- Записи йдуть у порядку появи оголошень у файлі. За того самого шляху, вмісту й середовища повторна успішна перевірка дає байтово однаковий звіт і той самий код завершення.
- Код `0` означає порожній звіт, `1` — щонайменше одну знахідку; в обох випадках stderr порожній. Ці коди характеризують весь запуск, а не окрему знахідку.
- Помилка аргументів, читання або розбору дає код `2`, діагностику в stderr і порожній stdout. Це охоплює відсутній файл, невалідний UTF-8 і синтаксичну помилку після потенційної знахідки. Тому читач відрізняє чистий файл від невдалої перевірки.

## Корпус прикладів

Три пари «знахідка — чистий приклад» у `tests/fixtures/empty-rust-test/` показують, яка мінімальна зміна прибирає спрацювання. У `expected.tsv` один рядок даних відповідає одному файлу; три поля розділені табуляцією, UTF-8: `path` — шлях від каталогу корпусу, `pair` — ідентифікатор пари, `lines` — `[N]` для очікуваної позиції або `[]` для чистого прикладу. Одинична позиція — властивість прикладів цього корпусу: кілька знахідок в одному файлі покриває окремий CLI-тест. Докладніше — у [README корпусу](../../../tests/fixtures/empty-rust-test/README.md).
