# Індекс домену

## Результати аналізу

| Документ | Призначення |
|---|---|
| [Знахідка](entities/finding.md) | Вказує читачеві місце спрацювання правила у файлі, ідентифікатор правила та повідомлення. |
| [Звіт складності](entities/complexity-report.md) | Показує суму цикломатичної чи когнітивної складності або розміру коду в рядках (за `--metric`) `.ts` коміту або локального файла чи теки й внесок кожного файла або причину його відсутності. |
| [Звіт дублювання](entities/duplication-report.md) | Показує, які блоки `.ts` повторюються, де лежать їхні входження та яку частку фізичних рядків вони покривають, а за неповного входу — нижню межу покриття. |
| [Звіт покриття](entities/coverage-report.md) | Показує покриття рядків і гілок `.ts` коміту чи теки за готовими звітами LCOV: знаменники й непокриті частини кожного файла, незіставлені шляхи та підсумок, а за невідповідності — неповний результат. |
| [Quality gate](entities/quality-gate.md) | Дає вердикт «пройдено / не пройдено» для зміни між двома комітами: чи не зросли суми знахідок правил і дублювання, та показує місця порушення. |
