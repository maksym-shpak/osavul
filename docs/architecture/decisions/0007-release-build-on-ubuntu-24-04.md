# ADR-0007: CI й релізи на Ubuntu 24.04
Статус: `Accepted`

## Контекст

Осавул потрібен і на хості Руни (Ubuntu 26.04, glibc 2.43), і в її віртуальних машинах, де виконуються перевірки й команди агентів (Ubuntu 24.04, glibc 2.39; стан на 2026-11-28). Бінарник релізу `v0.1.0-rc.1`, зібраний на 26.04, вимагає glibc 2.39: у гості він міг би запуститися лише впритул, і наступна збірка могла б вимагати новішої версії.

## Рішення

GitHub Actions перевіряє кожен pull request і push у `main`, а за тегом `v*` публікує реліз. Перевірки й збірка єдиної цілі `x86_64-unknown-linux-gnu` виконуються на `ubuntu-24.04` — найстарішій системі, де бінарник потрібен. Реліз містить архів, `SHA256SUMS` і attestation походження; опублікований реліз незмінний.

## Альтернативи

Збірку на 26.04 відкинуто: вона не гарантує запуску в гості. Статичну збірку з musl не перевіряли. Збірку на сервері відкинуто: вона потребувала б там toolchain і не дала б одного перевіреного артефакту. Збірки Windows і macOS людина відклала.

## Наслідки

- Один бінарник придатний для хоста й гостя; запуск на системі зі старішою за 2.39 glibc не гарантується.
- Підняття версії раннера потребує спершу перевірити версію системи гостя.
- Windows і macOS лишаються цільовими за [ADR-0003](0003-target-platforms.md), але CI їх не перевіряє й релізів для них немає.
- Виправити опублікований реліз не можна: потрібен новий тег.
