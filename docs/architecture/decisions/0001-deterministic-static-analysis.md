# ADR-0001: Фундамент довіри — детермінований статичний аналіз
Статус: `Accepted`

## Контекст

Код, згенерований ШІ, є ймовірнісним. За [принципами проєкту](../../../README.md#принципи) перевіряти його лише іншою LLM дорого, повільно й без гарантій. Інші мотиви невідомі.

## Рішення

Основою довіри Осавула є точний, відтворюваний статичний аналіз: правила застосовуються до тексту без виконання коду й без участі моделі.

## Альтернативи

Перевірка іншою LLM відкинута з причин вище. Чи розглядалися інші варіанти — невідомо.

## Наслідки

- Повторна успішна перевірка того самого входу за тих самих умов дає той самий звіт і код завершення; див. [Знахідку](../../domain/entities/finding.md).
- Результат можна використовувати як жорстку вимогу до агента, а не як оцінку.
