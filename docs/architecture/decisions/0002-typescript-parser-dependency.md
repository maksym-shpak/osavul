# ADR-0002: Вбудований парсер TypeScript Oxc
Статус: `Accepted`

## Контекст

Методика `ts-cyclomatic` потребує синтаксичного дерева TypeScript, яке розрізняє реалізацію функції й сигнатуру, умовний вираз і умовний тип, звичайні файли та `.d.ts`. За [ADR-0001](0001-deterministic-static-analysis.md) аналіз має бути відтворюваним і не виконувати код.

## Рішення

Вбудувати у Rust-бінарник парсер Oxc версії 0.160.0 і зафіксувати його в `Cargo.lock`. Прототип підтвердив збірку на Rust 1.100.0, режим декларацій і доступність діагностик.

## Альтернативи

Власний лексер відкинуто через ризик помилок у граматиці. Запуск TypeScript Compiler API потребував би Node.js у середовищі користувача й порушив би самодостатність бінарника.

## Наслідки

- Числа залежать від версії парсера: її зміна потребує повторного виміру й, якщо змінює бали, нової версії методики.
- Збільшуються обсяг залежностей і час першої збірки.
- Бінарник не потребує зовнішніх середовищ виконання.
