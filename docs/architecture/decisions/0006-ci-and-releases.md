# ADR-0006: CI й релізи в GitHub Actions
Статус: `Superseded by ADR-0007`

## Контекст

Осавул має замінити SonarQube на сервері з Ubuntu 26.04 (x86_64, стан на 2026-11-28). Серверу потрібен готовий перевірений бінарник, а автоматичної перевірки змін досі не було. Репозиторій публічний.

## Рішення

GitHub Actions перевіряє кожен pull request і push у `main`, а за тегом `v*` публікує реліз. Збирається лише `x86_64-unknown-linux-gnu` на `ubuntu-26.04` — тій самій версії ОС, що й сервер, тож версія glibc збігається. Реліз містить архів, `SHA256SUMS` і attestation походження; опублікований реліз незмінний.

## Альтернативи

Збірку на сервері відкинуто: вона потребувала б там toolchain і не дала б одного перевіреного артефакту. Збірки Windows і macOS людина відклала.

## Наслідки

- Windows і macOS лишаються цільовими за [ADR-0003](0003-target-platforms.md), але CI їх не перевіряє й релізів для них немає.
- Запуск бінарника на старішому Linux не гарантується.
- Виправити опублікований реліз не можна: потрібен новий тег.
